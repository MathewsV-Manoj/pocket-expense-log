# Pocket Expense Log

> A tiny spending log for noticing where your money went, without the guilt.

## How to use it

- Add an expense whenever you remember; imperfect notes are still helpful.
- Group similar purchases if that feels simpler.
- At the end of the week, spot one thing that surprised you.

## A small note to yourself

Awareness comes first. You do not have to fix everything at once.
